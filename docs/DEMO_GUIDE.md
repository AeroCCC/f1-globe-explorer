# F1 全球赛道探索器演示指南

本指南用于录制作品集展示素材，只覆盖 Web 桌面端。

## 推荐录制规格

- 画布：1440x900
- 时长：45 到 60 秒
- 内容：不录制浏览器地址栏，仅录制应用主体区域
- 形式：短视频优先，必要时可导出 GIF

## 演示流程

1. 打开首页，展示 3D 地球、右侧赛道抽屉和底部状态栏。
2. 拖拽地球，让赛道点位和云层动效可见。
3. 点击一个亚洲赛道点位，展示自动聚焦和 Marker 高亮。
4. 切换“历史”和“赛历”，展示数据面板稳定切换。
5. 切换“AI 解读”，点击“生成 AI 分析”。
6. 如果已配置 DeepSeek，展示生成结果；如果未配置，展示明确错误和“重试生成”按钮。
7. 结束画面停留在 AI 解读面板，确保项目名称和状态栏可见。

## 上线前确认

- Vercel 环境变量已配置 `DATABASE_URL`、`DEEPSEEK_API_KEY`、`DEEPSEEK_MODEL`。
- `npm run db:migrate` 和 `npm run db:seed` 已在目标数据库完成。
- `npm run lint`、`npm test`、`npm run build` 均通过。
